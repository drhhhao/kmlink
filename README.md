# kmlink

两台 Windows 电脑共用一套键盘鼠标，外加剪贴板同步、两台声音互通。Rust 写的单个 exe，平时常驻内存只有几 MB。

## 功能

- **跨屏**：鼠标推到两台相邻的那条边就过去，推回来就回来；键盘跟着走。
- **键盘跟随**（可选）：键盘打到你最后在用的那只鼠标所在的电脑。拿起另一台的鼠标一动，打字就跟过去。
  键盘一换到哪台，那台底部就弹一颗小提示「键盘 某某电脑」，两台同时只留一颗。
- **剪贴板同步**：复制的文字、图片自动同步到另一台，两台同时弹「某某电脑 已复制」。
- **声音互通**（可选）：每台把自己正在放的声音发给对方，在设置窗口里选：关 / 本机听 / 对方听 / 两台都放。
- **加密**：X25519 + 预共享配对密钥 + ChaCha20-Poly1305。
- **WiFi 友好**：被控端对鼠标移动做自适应平滑播放，无线攒包时不卡顿。

## 环境

- Windows 10 / 11（声音互通需要 Build 20348 以上）
- 两台在同一局域网，两台运行同一版本

## 编译

```
cargo build --release
```

产物在 `target\release\kmlink.exe`。需要 Rust 1.85 以上（edition 2024）。

## 使用

1. 两台都运行 `kmlink.exe`，防火墙弹窗点「允许访问」。第一次会自动打开设置窗口。
2. 在一台的设置里点「配对密钥」旁的「复制」，粘贴到另一台；填上对方 IP。
3. 在设置窗口的画布里把对方的屏幕拖到和实际摆放一致的位置。改完即生效，几秒内两台连上。

日常：

- **Scroll Lock**：在本机时锁定不跨屏（再按解锁）；在对方时立刻回到本机。
- **托盘菜单**：设置 / 暂停共享 / 键盘跟随 / 开机自启 / 打开配置文件夹 / 退出。
- 配置文件和日志在 `%APPDATA%\kmlink\`（`config.toml`、`kmlink.log`）。

## 已知限制

- 前台是管理员窗口（任务管理器、管理员命令行）时不跨屏，这是 Windows 的权限限制；需要的话以管理员身份运行 kmlink。
- 锁屏、UAC 弹窗、Ctrl+Alt+Del 时自动回到本机。
- 对方 2.5 秒没有回应（断网、睡眠、退出）时鼠标自动回到本机，网络恢复后自动重连。
