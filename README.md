# kmlink

两台 Windows 电脑共用一套键盘鼠标，外加剪贴板同步、两台声音互通。Rust 写的单个 exe，平时常驻内存只有几 MB。

## 功能

鼠标、键盘、声音、剪贴板各有自己的开关，互不影响（鼠标、键盘、声音的开关两台同步）：

- **鼠标**：推到两台相邻的那条边就过去，推回来就回来。
- **键盘**：跟着鼠标走；也可以开「跟随鼠标」——键盘打到你最后在用的那只鼠标所在的电脑，拿起另一台的鼠标一动，打字就跟过去。
  只开键盘、不开鼠标时总是这样跟随。键盘关着、鼠标开着时，鼠标过去了按键也留在本机。
  键盘一换到哪台，那台底部就弹一颗小提示「键盘 某某电脑」，两台同时只留一颗。
- **剪贴板同步**：复制的文字、图片自动同步到另一台，两台同时弹「某某电脑 已复制」。
- **复制粘贴文件**：在一台资源管理器里复制文件或文件夹，到另一台直接粘贴。复制时只发文件清单，粘贴时才传内容；
  传的时候灵动岛长成一张卡片，玻璃里灌水显示进度，光标移上去可以取消。插着 USB 线约 18～20 MB/s，没插线走局域网。线断了 30 秒内接上就接着传，传不完会报错，
  不会留下半截文件。插着线、总共不超过 50 MB 时会先取到本机，微信、QQ 也能直接粘贴。剪贴板页的「文件」开关可以关掉。
- **声音互通**：每台把自己正在放的声音发给对方，选在 1 号、2 号还是两台一起放；音量可调。
- **加密**：X25519 + 预共享配对密钥 + ChaCha20-Poly1305。
- **WiFi 友好**：被控端对鼠标移动做自适应平滑播放，无线攒包时不卡顿。
- **USB 线直连**（可选）：用 SmartKMLink 这类带串口的键鼠对拷线把两台连起来，kmlink 自动改走线（往返 < 1ms，不受 WiFi 断流影响），
  不用填 IP；拔掉线自动回落到网络，插回来自动换回线。环境变量 `KMLINK_CABLE=off` 关掉，`KMLINK_CABLE=COM5` 指定串口。

## 环境

- Windows 10 / 11（声音互通需要 Build 20348 以上）
- 两台在同一局域网，两台运行同一版本

## 编译

```
cargo build --release
```

产物在 `target\release\kmlink.exe`。需要 Rust 1.85 以上（edition 2024）。

## 使用

1. 两台都运行 `kmlink.exe`，防火墙弹窗点「允许访问」。第一次会自动打开设置窗口。
2. 在一台设置窗口的「连接」页点「配对密钥」旁的「复制」，粘贴到另一台；填上对方 IP。
3. 在「鼠标」页把对方的屏幕拖到和实际摆放一致的位置。改完即生效，几秒内两台连上。
4. 设置窗口左边的侧栏里，鼠标、键盘、声音、剪贴板各有一页，页头的开关单独开关这一项。

日常：

- **暂停热键**（默认 Scroll Lock，可在设置窗口「通用」页点键帽换成 F1～F24、Pause、Insert 等功能键）：在本机时暂停共享——
  不跨屏、键盘不过去、剪贴板不同步、声音也停（再按恢复）；在对方时立刻回到本机。
- **托盘面板**：右键托盘图标弹出（左键直接打开设置窗口）——暂停共享、鼠标 / 键盘 / 声音开关、声音在哪放、检查更新、设置、退出。
- **检查更新**：启动后和每天自动查 GitHub Release，有新版一键更新两台（下载后校验 SHA256 再替换）。
- 配置文件和日志在 `%APPDATA%\kmlink\`（`config.toml`、`kmlink.log`）。

## 已知限制

- 前台是管理员窗口（任务管理器、管理员命令行）时不跨屏，这是 Windows 的权限限制；需要的话以管理员身份运行 kmlink。
- 锁屏、UAC 弹窗、Ctrl+Alt+Del 时自动回到本机。
- 对方 2.5 秒没有回应（断网、睡眠、退出）时鼠标自动回到本机，网络恢复后自动重连。
